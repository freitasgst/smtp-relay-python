# SMTP Relay
Use of Python library `requests` to send messages to a google chat

## Requirements
- Make
- Python 3.12
- Pip >= 21.0.1
- Other requirements: 
    - requirements.txt 
    - requirements-dev.txt (development dependencies)

## Usage
```
make install
```

## Contributing

### Installing dev environment requirements:
```
make install-dev
```

### Testing
```
make coverage
```
